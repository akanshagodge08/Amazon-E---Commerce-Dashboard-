# Amazon E-Commerce Dashboard 📊

An end-to-end data analytics project featuring an interactive Power BI dashboard, SQL queries, and a structured project workflow analyzing Amazon e-commerce data.

## 🚀 Project Overview
This repository contains a complete business intelligence solution designed to analyze e-commerce performance metrics, sales trends, customer behavior, and product insights. 

## 📁 Repository Structure
* **`AMAZON_PROJECT_Akansha.pbix`** - The primary Power BI dashboard file containing interactive visualizations and data models.
* **`Powerbi_SQL file.sql`** - SQL scripts used for data extraction, transformation, and querying.
* **`Amazon_E-Commerce_Akansha_PPT.pptx`** - Presentation slides summarizing project insights and findings.
* **`Amazon_E-Commerce_tasks.docx`** - Documentation detailing project requirements, steps, and execution tasks.

## 🛠️ Tools & Technologies Used
* **Power BI:** Data visualization, DAX measures, and interactive reporting.
* **SQL:** Data extraction and backend querying.
* **Microsoft PowerPoint & Word:** Project reporting and documentation.

## 📊 Key Dashboard Features
* **Sales Performance:** Track overall revenue, order volume, and profit trends over time.
* **Product Analysis:** Identify top-performing product categories and best-sellers.
* **Customer Insights:** Breakdown of customer demographics and purchasing patterns.
